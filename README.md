# 나의 인생시 자서전 — 배포 안내

중학생이 인생시 한 편을 골라, 나이별로 지나온 삶과 다가올 삶을 돌아보며 자서전 에세이를 쓰고 제출하는 웹 앱입니다.

- 화면(앱): **GitHub Pages**에 올립니다 → `index.html`
- 제출물 저장: **구글 시트 + Apps Script**가 맡습니다 → `Code.gs`
- 관리자 비밀번호(1004)는 `Code.gs`에만 있어서, 공개되는 깃허브 코드에는 드러나지 않습니다.

> ⚠️ `Code.gs`는 깃허브에 올리지 마세요. `index.html`(과 원하면 이 README)만 올립니다.

---

## 1단계. 구글 시트에 저장 서버 만들기 (약 5분)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. 이름 예: `인생시 자서전 제출`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본으로 들어 있는 코드를 모두 지우고, `Code.gs` 파일 내용을 전부 붙여 넣은 뒤 **저장(💾)** 합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 톱니바퀴(유형 선택) → **웹 앱**
   - 설명: 아무거나 (예: v1)
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자** ← 꼭 이것으로 (학생이 로그인 없이 제출하려면 필요)
5. **배포**를 누르면 권한 승인 창이 뜹니다. 본인 계정 선택 → "고급" → "(프로젝트 이름)(으)로 이동(안전하지 않음)" → 허용.
   (내가 만든 스크립트라서 나오는 일반적인 경고입니다.)
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
   브라우저 주소창에 붙여 넣어 `"인생시 자서전 서버가 작동 중입니다"`가 보이면 성공입니다.

## 2단계. index.html에 서버 주소 넣기

`index.html`에서 아래 줄을 찾아 따옴표 안에 1단계의 URL을 넣고 저장합니다.

```js
const API_URL = "";
```
↓
```js
const API_URL = "https://script.google.com/macros/s/....../exec";
```

## 3단계. GitHub Pages에 올리기 (git 설치 없이 웹에서)

1. github.com에 로그인 → 오른쪽 위 **+ → New repository**
   - 이름 예: `life-poem-autobiography` / **Public** 선택 → Create repository
2. 저장소 화면에서 **uploading an existing file** 링크(또는 Add file → Upload files)를 누르고 `index.html`을 끌어다 놓은 뒤 **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다:
   `https://<깃허브아이디>.github.io/life-poem-autobiography/`
   이 주소를 학생들에게 나눠 주면 됩니다.

## 사용하기

- **학생**: 주소 접속 → 학번·이름 입력 → 6단계 작성 → 제출. 같은 학번·이름으로 다시 들어오면 이어 쓰거나 고쳐서 다시 제출할 수 있습니다(같은 학번은 덮어쓰기).
- **선생님**: 첫 화면 아래 **관리자 페이지** → 비밀번호 `1004` → 목록·상세 보기, 삭제, CSV 내려받기.
  구글 시트의 `제출목록` 탭에서도 모든 제출물을 바로 볼 수 있습니다.

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| "아직 제출 서버가 연결되지 않았습니다" | `index.html`의 `API_URL`이 비어 있음 → 2단계 |
| 제출하면 "제출하지 못했습니다" | Apps Script 배포의 액세스 권한이 "모든 사용자"인지 확인 |
| `Code.gs`를 고쳤는데 반영이 안 됨 | 배포 → **배포 관리** → 연필 → 버전: **새 버전** → 배포 (URL은 그대로 유지) |
| 비밀번호를 바꾸고 싶음 | `Code.gs` 맨 위 `ADMIN_PASSWORD` 수정 후 위처럼 새 버전으로 배포 |
| 학교 PC에서 깃허브 페이지가 바뀐 내용이 안 보임 | 1~2분 기다린 뒤 `Ctrl + F5` |

## 참고

- 학생이 쓰던 내용은 그 기기(브라우저)에 자동 임시 저장됩니다. 공용 PC라면 제출 후 "처음 화면으로"를 누르게 해 주세요.
- 학번과 이름을 알면 그 학생의 제출 글을 불러올 수 있는 구조입니다(이어 쓰기용). 더 엄격하게 하려면 말씀해 주세요.
- 시 전문은 저작권 때문에 앱에 넣지 않고, "전문 찾아보기" 링크로 학생이 직접 찾아 읽도록 했습니다.
